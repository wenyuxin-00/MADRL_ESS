Multi-Agent Deep Reinforcement Learning for Coordinated Energy Management of Prosumers with EVs, Batteries, and PV

关键词：

- Low-voltage distribution grid with multiple prosumers
- Coordinated scheduling of BESS, PV curtailment, and EV charging

答辩稿：

本研究关注低压配电网中多个 prosumer 的协同能源管理问题。随着住宅侧 PV、stationary battery 和 EV charging 的增加，用户侧资源具有更高的灵活性，但也引入了新的耦合问题。一方面，电池和 EV 可以根据电价进行调度以降低运行成本；另一方面，多个用户同时充电或充放电会影响电压、线路负载和变压器负载。

因此，本 thesis 的核心问题是：如何让多个 prosumer 在分布式执行的条件下，同时考虑经济性、EV 出行需求和配电网安全？为此，我构建了一个基于 pandapower 的低压配电网环境，并比较了 MADRL、MPC、ADMM-MPC 和 rule-based controller 的表现。


Slide 2 Problem Definition

PPT 放：

标题：
Problem Definition

文字：

- \(N=3\) prosumers connected to SimBench low-voltage grid
- Each prosumer owns load, PV, BESS, and EV
- Controller decides battery power, PV utilization, and EV charging
- Objective: minimize total operating cost while satisfying device and grid constraints

公式 LaTeX：

```latex
P^{net}_{i,t}=L_{i,t}-G^{use}_{i,t}+P^b_{i,t}+P^{ev}_{i,t}
```

```latex
\min \sum_{t=0}^{T-1}\sum_{i=1}^{N}
\tilde p_t\Delta t\left(P^b_{i,t}+P^{ev}_{i,t}\right)
```

```latex
SOC^b_{\min}\le SOC^b_{i,t}\le SOC^b_{\max}
```

```latex
SOC^{ev}_{i,t^{dep}}\ge SOC^{ev}_{req}
```

```latex
V_{\min}\le V_{b,t}\le V_{\max},\qquad
\lambda^{line}_{\ell,t}\le 100\%,\qquad
\lambda^{tr}_{m,t}\le 100\%
```

答辩稿：

首先定义系统问题。每个 prosumer 的净负荷由本地负荷、PV 利用功率、电池功率和 EV 充电功率共同决定。这里电池功率 \(P^b\) 为正表示充电，为负表示放电；EV 只允许充电，不考虑 V2G。

优化目标是最小化所有 prosumer 在整个 episode 中的总运行成本。这个目标不仅包含 EV charging cost，也包含 battery charging cost 和 discharging benefit。同时系统必须满足三类约束：第一是电池 SoC 约束，第二是 EV 离家时的 SoC requirement，第三是配电网安全约束，包括电压、线路和变压器负载。

这个问题的难点在于它不是一个单步决策问题。电池 SoC 和 EV SoC 会把当前动作和未来可行域耦合起来；多个 prosumer 的动作又通过 power flow 在电网中耦合起来。

公式 LaTeX：

```latex
\rightarrow

```

答辩稿：

系统工作流程可以概括为一个闭环。首先，环境读取负荷、PV 和电价数据，并由 LSTM 生成未来 horizon 的预测序列。然后每个 MADRL actor 基于本地 observation 输出三维动作，分别对应 battery、PV 和 EV。

动作不会直接执行，而是先经过本地可行性检查；如果启用 safety projection，还会进一步修正 battery power 和 PV curtailment。随后环境更新 SoC 和净负荷，并调用 pandapower 进行 AC power flow。最后，环境根据经济收益、EV 约束、电池正则化和电网安全状态计算 reward，并把 transition 存入 replay buffer 用于训练。

答辩稿：

Reward 设计同时包含经济目标、EV mobility requirement、电池行为和电网安全。battery reward 鼓励低价充电、高价放电；EV cost 使 agent 避免不必要的高价充电；departure penalty 约束离家 SoC；progress penalty 提供更密集的 EV 充电引导；price-aware penalty 在 hard 线中用于减少高价时段充电。

Slide 11 Grid Safety Projection

PPT 放：

流程图：

Raw action
-> local SoC feasibility
-> safety projection on \([P^b,G^{curt}]\)
-> final action
-> pandapower validation

文字强调：

- Projection modifies BESS and PV curtailment
- EV charging is not directly projected by grid safety layer
- Improves safety but changes action-reward relationship

公式 LaTeX：

```latex
x_t=
[P^b_{1,t},\ldots,P^b_{N,t},
G^{curt}_{1,t},\ldots,G^{curt}_{N,t}]
```

```latex
P^{base}_{i,t}=L_{i,t}-G_{i,t}+P^{ev}_{i,t}
```

```latex
V_t\approx V^{base}+S^V\Delta P_t
```

```latex
\lambda^{line}_t\approx \lambda^{base}+S^{line}\Delta P_t
```

```latex
r_j^Tx\le b_j
```

```latex
x\leftarrow
x-\frac{\max(0,r_j^Tx-b_j)}{\|r_j\|_2^2}r_j
```

答辩稿：

Safety projection 是 reward penalty 之外的硬修正机制。它不是等 unsafe action 执行后再惩罚，而是在动作执行前直接修正动作。

投影变量只包括 battery power 和 PV curtailment，不包括 EV charging。原因是 EV 代表用户出行需求，本文把 EV 约束单独处理。投影器通过有限差分估计 voltage 和 line loading 对 net injection 的 sensitivity，然后把安全约束写成 half-space，并逐行进行 projection。

算法上，这会带来一个重要影响：actor 输出的 raw action 和环境中实际执行的 action 不再完全一致。因此 projection 虽然提升电网安全，但也可能改变 policy gradient 看到的 action-reward relationship，使得 actor 学到的 battery arbitrage 策略被频繁裁剪。这一点是后面分析 projection 经济性下降的关键。


Slide 12 MADRL Training Algorithm

PPT 放：

标题：
MADRL Training: CTDE + TD3-style Actor-Critic

流程图：

Initialize actors/critics
-> collect transitions
-> replay buffer
-> critic update
-> delayed actor update
-> target soft update

公式 LaTeX：

```latex
a_{i,t}=\pi_i(o_{i,t};\theta_i)
```

```latex
Q_i(o_{1:N,t},a_{1:N,t};\phi_i)
```

```latex
R^{(n)}_{i,t}
=
\sum_{k=0}^{n-1}\gamma^kr_{i,t+k},
\qquad n=48
```

```latex
y_{i,t}
=
R^{(n)}_{i,t}
+
\gamma^n(1-d_t)
\min
\left(
Q'_{i,1}(o_{t+n},a'_{t+n}),
Q'_{i,2}(o_{t+n},a'_{t+n})
\right)
```

```latex
L^Q_i
=
\left(Q_{i,1}(o_t,a_t)-y_{i,t}\right)^2
+
\left(Q_{i,2}(o_t,a_t)-y_{i,t}\right)^2
```

```latex
a^{pol}_{i,t}
=
\operatorname{guard}(\pi_i(o_{i,t}))
```

```latex
L^\pi_i
=
-Q_{i,1}(o_t,a_{1,t},\ldots,a^{pol}_{i,t},\ldots,a_{N,t})
```

```latex
\theta'_i\leftarrow(1-\tau)\theta'_i+\tau\theta_i
```

```latex
\phi'_i\leftarrow(1-\tau)\phi'_i+\tau\phi_i
```

答辩稿：

MADRL 采用 centralized training and decentralized execution。执行时，每个 actor 只使用自己的 observation；训练时，critic 接收所有 agents 的 joint observation 和 joint action，从而学习 agent 之间通过电网产生的耦合影响。

训练算法接近 multi-agent TD3。每个 agent 有 actor 和 twin critics，以减少 Q-value overestimation。Replay buffer 使用 n-step return，这里 \(n=48\)，对应约 12 小时，因此 reward target 可以覆盖 EV 夜间充电窗口中的长时序影响。

Actor update 时，只替换 joint action 中当前 agent 的动作，其他 agent 的动作保持 batch 中的值。这使 critic 可以评估单个 agent 政策改进对联合系统的边际影响。

答辩稿：

Baseline 用于说明 MADRL 相对简单规则和优化方法的优劣。Local MPC 每个 prosumer 独立求解，因此经济性通常较好，但缺少 network-level coordination。ADMM-MPC 在 Local MPC 基础上增加 transformer aggregation constraint，因此安全性更好。

Rule-based controller 则作为简单参考。无电池版本只要 EV connected 且未满就以最大功率充电；有电池版本额外根据电价分位数进行电池充放电。这类方法计算成本低，但不能主动利用 forecast，也不能学习 load、PV、price、EV SoC 和 grid 状态之间的复杂关系。

第一个改进是增加 EV cost weight，把 EV charging cost 在 reward 中放大到 1.5 倍。结果上，它确实解决了 departure SoC 问题，below target 从 2 次变为 0 次。

答辩稿：

Progress penalty 是更有效的 soft 改进。它不是简单提高 EV charging cost 的权重，而是在 EV 连接窗口内构建一条从 arrival SoC 到 required SoC 的线性参考轨迹。如果实际 EV SoC 落后于这条轨迹，就产生 penalty。

算法上，这相当于把原本只在 departure step 出现的 sparse constraint 转换成 dense temporal guidance。Critic 可以在整个夜间窗口中持续观察到 EV SoC 是否落后，因此 credit assignment 更容易，actor 也更容易学到“逐步充电”而不是“最后补救”。

结果上，Base + Progress 同样实现 0 次 below target，但 total cost 低于 Cost Weight，storage profit 也更高。这说明 progress penalty 比单纯调 reward weight 更适合表达 EV mobility constraint。

Emergency charging 在 soft 线中表现也不好。原因是它只在离家前短窗口补救，而不是在整个 connection window 内保持可行性。这样会产生充电集中，可能错过低价时段，也可能叠加到电网高负荷时段，因此既不稳定满足 EV target，也可能加重 grid stress。


Slide 20 Hard Constraint Implementation

PPT 放：

标题：
Hard EV Constraint

文字：

- Preserve feasibility of departure SoC
- Actor can charge more, but not less than minimum required
- Turns sparse EV requirement into execution-layer feasibility correction

公式 LaTeX：

```latex
\Delta SOC^{future,\max}_{i,t}
=
\frac{K^{future}_tP^{ev,\max}_i\Delta t\eta_{ev}}{C^{ev}_i}
```

```latex
P^{ev,req}_{i,t}
=
\max
\left(
0,
\frac{(SOC^{ev}_{req}-\Delta SOC^{future,\max}_{i,t}-SOC^{ev}_{i,t})C^{ev}_i}
{\Delta t\eta_{ev}}
\right)
```

```latex
P^{ev}_{i,t}
=
\min
\left(
P^{ev,\max}_i,
\max(P^{ev,rl}_{i,t},P^{ev,req}_{i,t})
\right)
```

答辩稿：

Hard mode 的核心思想是把 EV departure requirement 从 reward learning 问题转移到 action execution 层。每个 step 计算未来剩余连接时间内最多还能增加多少 SoC。如果当前不充足，从当前 step 开始就可能无法在离家前达到目标，那么环境会计算一个 minimum required charging power。

最终执行功率是 actor 请求功率和 required minimum power 的最大值。也就是说，actor 仍然可以选择更高的充电功率，但不能选择低于维持可行性的功率。

算法上，hard mode 减少了 EV feasibility 对 reward learning 的依赖，因此降低了 sparse reward 带来的 credit assignment 难度。但它也引入了 action correction，可能与 actor 的原始经济调度意图发生冲突。

Slide 26 Conclusion and Outlook

PPT 放：

Conclusion：

1. MADRL learns coordinated scheduling of BESS, EV, and PV under grid feedback.
2. Soft reward-only EV control suffers from sparse departure signal; progress penalty improves learning.
3. Hard EV correction improves feasibility but must be combined carefully with grid projection.
4. Safety projection improves voltage and transformer safety but may weaken battery arbitrage due to action mismatch.

Outlook：

- Projection-aware training
- Better EV overcharging control
- Joint optimization of EV and grid safety constraints
- More robust forecast integration
- Larger network and more heterogeneous prosumers

答辩稿：

总结来说，本 thesis 构建了一个多 prosumer 的低压配电网能源管理框架，并将 EV、stationary battery、PV、LSTM forecast、pandapower power flow 和 MADRL training 集成到同一个实验链中。

实验表明，MADRL 可以学习到比 rule-based 更灵活的调度策略，尤其是 battery arbitrage 和 EV charging 与电价之间的关系。但 reward-only 的 soft EV constraint 存在 sparse signal 问题，因此 progress penalty 能显著改善 EV feasibility。Hard EV correction 可以更直接地保证 departure requirement，但它和 safety projection 叠加后，会改变 actor action 和 executed action 之间的关系，从而影响学习稳定性和经济性。

最终，如果优先考虑经济性，Base Hard 是较好的 MADRL controller；如果优先考虑 EV feasibility 和 grid safety，Projection Hard 是更稳健的选择。未来工作可以从 projection-aware training、更精细的 EV overcharging control，以及更大规模、更异构的 prosumer 网络继续扩展。
